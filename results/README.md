# Frozen main results

`LEADERBOARD_FROZEN_20261011.json` is the public aggregate derived from the
frozen 47-task by 9-configuration main experiment. The leaderboard is ranked by
strict reproduction success. Each configuration has denominator 47.

The public file records the SHA-256 fingerprints of the source fact pack and
two per-run adjudication ledgers. Those ledgers contain internal adjudication
and machine-path evidence and are not bundled in this lightweight repository.
The released aggregate therefore supports version identification and reported
count inspection, but not independent reconstruction of every adjudication.

Execution, delivery, replay match, and strict success are separate checks. A
matching replay does not by itself establish that the required method pipeline
was executed or that the delivery is complete.
